# W2 Spec Addendum — Calibration Core (in-sample only)

Companion to docs/W1_SPEC.md and docs/M3_SPEC_ADDENDUM.md. Same contract:
read fully, propose a plan per milestone, code only after approval.

## 0. Sequencing gate (hard precondition)

No W2 statistic runs on the full panel until the README containing the
pre-registered primary specification is committed and pushed. The commit
hash is the proof that the spec predates the results. If that commit does
not exist yet, stop and say so.

## 1. Fixed decisions (not open for re-litigation at planning time)

- **Data access:** all analysis reads go through
  `load_panel(P1_PATH)` with defaults — never raw parquet in analysis
  modules. That yields the 52,388 non-OOS rows and nothing else. Raw reads
  stay confined to `spikes/` sanity reports, per the M3 addendum carve-out.
- **Row exclusions at this step:** drop rows with `y` null or
  `resolution_ambiguous == True`, and count what was dropped in every
  report. These were deliberately kept in the panel (M3 addendum §3);
  calibration is where they exit.
- **Headline population:** pooled **ex-Sports** plus per-category
  breakdowns. Sports is always reported, never pooled into the headline.
- **Weighting:** primary results are equal-weighted per (market, snapshot)
  row. Volume-weighting is a W3 reconciliation axis, not a W2 spec.
- **Horizon covariate:** ex-ante only. Stratify by `days_to_sched_end`
  (known at snapshot time). `days_to_resolution` is ex-post and reserved
  for W3's stopping-time comparability analysis — it must not appear as a
  conditioning variable in any W2 primary result.
- **Repeated snapshots:** rows of the same market across months share one
  outcome. Event-level clustering (market ⊂ event) already covers this;
  no additional correction, but say so in the module docstring.
- **Null event_id:** orphan markets (event_id null in M1) form singleton
  clusters keyed by market_id. The bootstrap engine must handle this
  explicitly, with a test.

## 2. Milestones

### W2a — Inference engine first: `src/inference/bootstrap.py`

Built before any statistic, because every number in W2b-W2d gets its CI
from this one engine. Retrofitting inference after the stats exist is how
inconsistent CIs happen.

Sketch:

```python
@dataclass(frozen=True)
class BootstrapResult:
    point: dict[str, float]
    ci_low: dict[str, float]
    ci_high: dict[str, float]
    B: int
    seed: int

def event_bootstrap(
    df: pl.DataFrame,
    stat_fn: Callable[[pl.DataFrame], dict[str, float]],
    cluster_col: str = "event_id",
    B: int = 2000,
    seed: int = 0,
) -> BootstrapResult
```

- Resamples **clusters** (events) with replacement, reassembles the frame,
  applies `stat_fn` per draw. `stat_fn` returns a dict so multi-parameter
  stats (α and β together) refit once per draw, not once per parameter.
- Percentile CIs. Deterministic under a fixed seed.
- Performance target: a scalar stat on the 52,388-row frame at B=2000 in
  seconds, not minutes — precompute event → row-index mapping once,
  resample indices, avoid per-draw joins. Propose the approach before
  implementing if it deviates from this.
- Tests: seed reproducibility; cluster integrity (a stat engineered to
  detect a split cluster proves rows of one event always move together);
  singleton-cluster handling for null event_id; sanity on a synthetic
  dataset with known sampling distribution (e.g. cluster means) where the
  bootstrap CI must bracket the truth at roughly nominal rate.

Commit W2a on its own once green, per the granularity rule.

### W2b — Reliability diagrams + isotonic overlay

- Fixed decile bins on p (edges 0.0, 0.1, ..., 1.0 — after the panel's
  own clip these are effectively [0.01, 0.99]); empirical frequency per
  bin with Wilson intervals for the figures.
- Isotonic overlay to show the binning isn't driving the shape. Prefer a
  small hand-rolled PAVA (≈30 lines, unit-tested against a worked example)
  over pulling in scikit-learn for one function. If you disagree, argue it
  at plan time, don't just add the dependency.
- Outputs: per-category + ex-Sports pooled figures under
  `reports/figures/`, generated by `src/calibration/reliability.py`, no
  logic in notebooks. matplotlib joins requirements.txt (pinned) — flag it
  in the plan.

### W2c — Brier, Murphy decomposition, skill score

- Brier score; Murphy decomposition (reliability − resolution +
  uncertainty) computed on the same fixed bins; Brier skill score vs the
  category base rate; log-loss as a robustness column.
- CIs on all of it via `event_bootstrap`.
- Test: a tiny hand-computed example where the decomposition identity
  holds exactly under the binned convention, so a refactor that silently
  breaks the identity fails loudly.

### W2d — Calibration regression + formal tests

- Primary estimand, exactly as pre-registered: logistic regression
  logit(P(Y=1)) = α + β·logit(p), per category and pooled ex-Sports.
  H0: (α, β) = (0, 1). Fit via statsmodels (pinned) or a small IRLS —
  propose which, with the tradeoff, at plan time.
- CIs: refit inside `event_bootstrap` (the engine's dict return exists
  for this). Analytical cluster-robust SEs may be reported alongside,
  clearly labeled, but the bootstrap is primary.
- Spiegelhalter's Z for overall calibration; per-bin exact binomial tests
  with Benjamini-Hochberg across bins within each category.
- Multiplicity framing in the output itself: the pooled ex-Sports (α, β)
  test is THE primary result; every other cell is labeled secondary.

### Gate D — sanity vs literature and internal consistency

Report-only spike (`spikes/gate_d.py`), same pattern as Gates A-C:

1. Slopes finite, and directionally sane: published work at comparable
   settings finds compression that grows with horizon (β above 1, rising
   with time to close). Exact magnitudes needn't match; a pooled β of 0.3
   or 5.0 means a bug hunt, not a finding.
2. Reliability curves roughly monotone; isotonic and binned versions tell
   the same story.
3. BSS > 0 in most cells (prices beat the base rate — if they don't,
   suspect the pipeline before suspecting the market).
4. n per cell vs the ~200 floor once category × horizon-tercile splits
   are applied — Other (1,708 non-OOS rows) is the known watch item.
5. Dropped-row accounting: ambiguous/null-y exclusions counted and
   reconciled against Gate C's numbers.

Exit: everything sane → W2 closes, W3 (reconciliation grid) opens. Any
check wildly off → stop, investigate, DECISIONS.md entry either way.
